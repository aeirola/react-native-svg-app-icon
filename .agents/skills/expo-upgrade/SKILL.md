## Our setup

- The Expo app lives in `example-expo/`. Run all Expo commands from that directory.
- It uses Continuous Native Generation (CNG): `ios/` and `android/` are gitignored and generated by `expo prebuild` (run from the `prepare` script). Never commit them or edit them by hand.
- The app is minimal: no Expo Router, no audio/video, no Reanimated, no postcss or custom Metro/Babel config. Skip upgrade guidance for features it does not use.
- `react-native-svg-app-icon` is installed from the repo root via `install-local` (`localDependencies`). Keep that intact.
- Dependencies are tracked in `example-expo/package.json` and `example-expo/package-lock.json`.

## Beta/Preview Releases

Beta versions use a `.preview` suffix and are published under the `@next` tag. Prefer the `latest` tag unless the user asks for a beta. Check tags with `npm view expo dist-tags`.

## Step-by-Step Upgrade Process

> If upgrading from SDK 55 or earlier, do not target SDK 56 or `expo@57.0.8` and below. They contain a Hermes V1 memory regression. Target `expo@57.0.9` or later.

From `example-expo/`:

1. Upgrade Expo and align dependencies

```bash
npx expo install expo@latest
npx expo install --fix
```

2. Run diagnostics: `npx expo-doctor`. Fix everything it reports.

3. Verify the generated native projects and icon generation still work:

```bash
rm -rf ios android .expo
npm run prepare   # expo prebuild + icon generation
```

4. Verify the JS bundle builds: `npx expo export -p ios --clear` (output goes to the gitignored `dist/`).

## Housekeeping

- Review release notes for the target SDK at https://expo.dev/changelog and check for breaking changes affecting `App.js`, `index.js` and `app.json`.
- Delete `sdkVersion` from `app.json` if present.
- Remove `"newArchEnabled": true` from `app.json`; the New Architecture is the default.
- Remove `expo.install.exclude` entries in `package.json` that are workarounds no longer needed.
- Remove outdated `patches/` if any exist.
- If `babel.config.js` / `metro.config.js` only contain Expo defaults, delete them.
- When removing a dependency, re-run `npx expo-doctor` and restore anything reported as a missing required peer.
- Update versioned docs links (`docs.expo.dev/versions/v<version>/`) in docs or agent instruction files, if any.
- Check `README.md` files for mentions of the old SDK version.
- Make sure the `svgAppIcon` config in `app.json` still works with the generator after the upgrade.
